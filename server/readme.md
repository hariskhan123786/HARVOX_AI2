# HARVOX AI 🤖

> AI Operating System for Developers

## Features
- 🧠 Multi-Provider AI (Groq, Gemini, Cohere)
- 💻 Code Generation & Debug Assistant
- 📁 File Intelligence System
- 🎙️ Voice Assistant
- 🌐 3D Hologram Interface
- 👑 Admin Control Center
- 💳 Pro Subscription System

## Tech Stack
- Frontend: React + Tailwind CSS + Three.js
- Backend: Node.js + Express.js
- Database: MongoDB
- AI: Groq + Gemini + Cohere

## Setup Instructions

### 1. Clone the repository
git clone https://github.com/yourusername/harvox-ai.git
cd harvox-ai

### 2. Setup Backend
cd server
npm install
cp .env.example .env
# Fill in your .env values
npm run dev

### 3. Setup Frontend
cd client
npm install
cp .env.example .env
# Fill in your .env values
npm run dev

## Environment Variables
See server/.env.example and client/.env.example
